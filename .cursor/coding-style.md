# Coding Style

## PHP

PSR-12.

Usar tipado.

Siempre declarar tipos de retorno.

Ejemplo

public static function init(): void

---

## Nombres

Clases

PascalCase

Variables

camelCase

Constantes

UPPER_CASE

Archivos

PascalCase.php

---

## Comentarios

Comentar únicamente bloques importantes.

No comentar código obvio.

---

## Funciones

Máximo una responsabilidad.

Si supera 40 líneas considerar dividirla.

---

## Clases

Una responsabilidad.

No crear clases gigantes.

---

## JavaScript

ES Modules.

Arrow Functions cuando sea posible.

const antes que let.

Nunca usar var.

---

## CSS

BEM.

No usar IDs.

Evitar !important.
