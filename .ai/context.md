# CavTheme

Starter WordPress desarrollado por Camilo Velosa.

Tecnologías

- WordPress
- PHP 8.1+
- Vite
- Sass
- ES Modules
- Vanilla JS

Arquitectura

Application
↓

Theme

↓

AssetManager

↓

Objetivo

Construir cualquier sitio web reutilizando este starter.

Nunca modificar la arquitectura.

Crear componentes reutilizables.

Siempre separar lógica de presentación.

Todas las vistas viven dentro de /views

Todo JS vive dentro de src/js

Todo SCSS vive dentro de src/scss
